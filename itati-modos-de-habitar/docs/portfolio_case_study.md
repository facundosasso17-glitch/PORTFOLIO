# Portfolio Case Study --- Villa Itatí

## From qualitative interviews to reproducible data analysis

### The challenge

How can qualitative material from urban research be transformed into a
structured dataset without losing the theoretical categories that gave
meaning to the original research?

### What I did

I built an analytical dataset from a qualitative study of Villa Itatí,
Quilmes, using eight selected interview cases.

The workflow combined:

**qualitative coding → data modeling → Python/Pandas → exploratory
analysis → visualization**

The dataset organizes information about:

-   everyday mobility;
-   social networks;
-   expectations of permanence;
-   representations of self and neighborhood;
-   territorial representations;
-   states of mobility.

### Why it matters

This project demonstrates a research workflow in which programming is
used not simply to calculate statistics, but to:

1.  structure qualitative evidence;
2.  document analytical decisions;
3.  detect patterns and contrasts;
4.  produce reproducible tables and visualizations;
5.  connect data analysis back to sociological interpretation.

### Key analytical insight

The cases show different articulations between mobility, community ties,
expectations and neighborhood representations. Care and community
networks can provide support and enable action while existing alongside
territorial fragmentation and institutional distance.

The project therefore treats "ways of inhabiting" as a multidimensional
analytical object rather than a single measurable outcome.

### Technical stack

**Python · Pandas · NumPy · Matplotlib · Jupyter Notebook · EDA ·
categorical data · cross-tabulation · data provenance · qualitative data
structuring**

### Dataset ethics

The public repository uses anonymized identifiers and excludes raw
transcripts, names, addresses and sensitive personal information.

during 2024 and developed within Sociology at the University of Buenos

the original qualitative research material.
